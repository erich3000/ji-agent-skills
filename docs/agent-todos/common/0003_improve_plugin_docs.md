## Context

To provide a better overview, each plugin should get its own README file.

## Tasks

- Create a `plugins` folder under the `docs` directory.
- Each plugin should have its own README file there, as a Markdown file named after the plugin (for example, `docs/plugins/agent-todos.md`).
- Move plugin-related information from the general root `README.md` into the corresponding plugin README files in the docs plugin directory.
- Update the general `README.md` to reference the plugin-specific README files.
