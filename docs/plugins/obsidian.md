# obsidian

`obsidian` provides skills for working with Obsidian vault content and Kanban boards.

## What It Does

- Creates and manages Obsidian Kanban plugin board files.
- Covers board structure, columns, card syntax, archive blocks, and settings sections.

## Skills

| Skill              | Description                                                                      |
| ------------------ | -------------------------------------------------------------------------------- |
| `/obsidian-kanban` | Creates and updates Obsidian Kanban boards with consistent format and structure. |
