# obsidian

`obsidian` provides skills for working with Obsidian vault content, Kanban boards, Obsidian Bases, and visual styling.

## What It Does

- Creates and manages Obsidian Kanban plugin board files.
- Enriches existing Kanban cards from linked note frontmatter (for example aliases and thumbnails).
- Installs curated CSS snippets for Kanban boards and Obsidian Bases tables.
- Covers board structure, columns, card syntax, archive blocks, and settings sections.

## Skills

| Skill                      | Description                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `/obsidian-kanban`         | Creates and updates Obsidian Kanban boards with consistent format and structure.           |
| `/obsidian-enrich-kanban`  | Enriches one existing Kanban board by using linked note frontmatter (title and thumbnail). |
| `/obsidian-kanban-styling` | Installs and customizes a Kanban CSS snippet (`.obsidian/snippets/kanban.css`).            |
| `/obsidian-bases-styling`  | Installs and customizes a Bases CSS snippet (`.obsidian/snippets/bases.css`).              |
