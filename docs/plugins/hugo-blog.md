# hugo-blog

`hugo-blog` provides skills for Hugo content creation and markdown proofreading.

## What It Does

- Scaffolds new Hugo content using archetypes and project conventions.
- Reviews markdown files for typos, grammar, consistency, and clarity.

## Skills

| Skill                    | Description                                                                            |
| ------------------------ | -------------------------------------------------------------------------------------- |
| `/hugo-new`              | Discovers archetypes and content conventions, then creates new content via `hugo new`. |
| `/markdown-proofreading` | Proofreads markdown files for language and formatting quality.                         |
